## ⚡ API REST

L'application expose une API publique rapide et mise en cache au niveau des edge servers Cloudflare :

### 1. Obtenir les offres
```http
GET https://fullremote-jobs.edounze.com/api/jobs
```

**Paramètres de requête supportés :**
- `region` : `worldwide` | `france` | `europe` | `americas` | `apac_mea`
- `lang` : `fr` | `en`
- `category` : `tech` | `devops` | `data_ai` | `design` | `product` | `marketing_sales`
- `q` : Recherche textuelle libre (ex: `react`, `kubernetes`, `devops`)

## 🛠️ Architecture & Sources

Le système s'appuie sur une pile 100% serverless Cloudflare :
- **Edge Computing** : Cloudflare Worker en ES Modules (`src/index.js`).
- **Cron Triggers** : Planificateur automatique `0 6 * * *` (tous les matins à 6h00 UTC).
- **Sources agrégées** :
  1. [Remotive API](https://remotive.com)
  2. [Jobicy API](https://jobicy.com)
  3. [Arbeitnow API](https://www.arbeitnow.com)
- **Normalisation** : Dédoublonnage, détection automatique de région géographique (🇫🇷, 🇪🇺, 🇺🇸, 🌏, 🌍), détection de langue et catégorisation métier.

## 💻 Installation & Déploiement

### Prérequis
- Node.js >= 18.x
- Compte Cloudflare avec CLI Wrangler

### Commandes utiles

```bash
# 1. Cloner le projet
git clone git@github.com:flouzzy/fullremote-jobs.git
cd fullremote-jobs

# 2. Installer les dépendances
npm install

# 3. Lancer en local
npm run dev

# 4. Déployer sur Cloudflare Workers
npm run deploy
```
