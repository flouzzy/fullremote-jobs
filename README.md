## ⚡ API REST & Flux RSS

### 1. Endpoint JSON des offres
```http
GET https://fullremote-jobs.edounze.com/api/jobs?region=worldwide&contract=cdi_fulltime&min_salary=75000&page=1&limit=30
```

**Paramètres disponibles :**
- `region` : `all` | `worldwide` | `france` | `europe` | `americas` | `apac_mea`
- `contract` : `all` | `cdi_fulltime` | `freelance_contract` | `cdd_parttime` | `internship`
- `lang` : `all` | `fr` | `en`
- `category` : `all` | `tech` | `devops` | `data_ai` | `design` | `product` | `marketing_sales`
- `min_salary` : Seuil de salaire minimum annuel en € ou $ (ex: `50000`, `75000`, `100000`)
- `q` : Recherche textuelle libre (ex: `kubernetes`, `golang`, `react`, `senior`)
- `page` : Numéro de page (défaut `1`)
- `limit` : Nombre d'offres par page (défaut `60`, max `150`)

### 2. Flux RSS 2.0 officiel
```http
GET https://fullremote-jobs.edounze.com/rss
```

### 3. Fiches SEO individuelles Google Jobs
```http
GET https://fullremote-jobs.edounze.com/jobs/:id
```
*Intègre les balises `schema.org/JobPosting` et OpenGraph pour une indexation directe dans Google For Jobs.*

## 🗄️ Base de données Cloudflare D1

Le projet supporte nativement **Cloudflare D1** pour stocker et indexer des milliers d'offres dans une base SQLite serverless distribuée.

```bash
# 1. Créer la base de données D1 sur Cloudflare (une seule fois)
npx wrangler d1 create fullremote-jobs-db

# 2. Appliquer les migrations en local
npm run db:migrate:local

# 3. Appliquer les migrations en production
npm run db:migrate:remote
```

## 🛠️ Installation & Déploiement

### Prérequis
- Node.js >= 18.x
- Compte Cloudflare avec CLI Wrangler

### Commandes utiles

```bash
# Cloner le projet
git clone git@github.com:flouzzy/fullremote-jobs.git
cd fullremote-jobs

# Installer les dépendances
npm install

# Tester la conformité du code
npm test

# Lancer en environnement local
npm run dev

# Déployer sur Cloudflare Workers
npm run deploy
```
